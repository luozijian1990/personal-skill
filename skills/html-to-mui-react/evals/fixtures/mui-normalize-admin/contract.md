# 功能草图契约

该 HTML 只表达功能，视觉无需保留，允许统一为克制的企业 MUI 风格。

必须保留：

- 资产列表字段：编号、名称、类型、状态；
- 关键字和状态筛选，以及查询、重置；
- 当前页、总页数、上一页、下一页；
- Loading、Empty、Error 和正常列表状态；
- 中文文案和桌面端信息结构。

不得把静态示例描述成真实后端能力。目标 viewport：桌面端 1280×800。

Fixture 约定：查询时先进入 Loading；关键字“加载中”保持 Loading，“错误”进入 Error，“无结果”进入 Empty，其他值返回正常列表；状态筛选要反映到结果；上一页/下一页必须改变当前页并在边界禁用。
